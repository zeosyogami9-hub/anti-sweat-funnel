# Funnel de Vente Vibe-Codé : T-Shirt Anti-Transpiration (Anti-Sweat)

Landing page d'entonnoir mono-produit optimisée pour la conversion publicitaire (Meta Ads, TikTok Ads) et reliée directement au checkout sécurisé de Shopify.

## 🚀 Fonctionnalités Clés
- **Sans distraction** : Header et Footer allégés (zéro fuite de trafic).
- **Sélecteur de Bundles (AOV Boost)** : Offres configurées pour 1 t-shirt, 2 t-shirts et Pack 3 t-shirts (Recommandé).
- **Direct Checkout (Cart Permalinks)** : Les boutons d'achat envoient directement le visiteur vers le paiement sécurisé de Shopify avec les remises appliquées.
- **Support des paiements locaux** : Prêt pour **Bizum**, Apple Pay et cartes bancaires.
- **Mobile-First & Ultra Rapide** : Conçu avec Tailwind CSS sans frameworks lourds.

## 🛠️ Configuration Shopify
1. Ouvrez `index.html`.
2. Mettez à jour la variable `SHOPIFY_STORE` avec votre nom de domaine Shopify (ex: `maboutique.myshopify.com`).
3. Remplacez les identifiants dans l'objet `VARIANTS` par vos réels Variant IDs Shopify.
